Session at a glance

Microsoft Agent 365: build agents, then govern them

An end-to-end demo: build a declarative Agent Builder agent, design a Copilot Studio production agent, submit or review the agent, then use Microsoft Agent 365 to observe, govern, and secure the agent estate.

Agent Builder

Fast declarative agent for Microsoft 365 Copilot with Zava order knowledge and guardrails.

Copilot Studio

Low-code production agent with topics, actions, approvals, analytics, and publish path.

Agent 365

Central registry, activity, governance, ownership, and security/compliance control plane.

What is currently demoable?

Agent Builder in Microsoft 365 Copilot

Create declarative agents from Microsoft 365 Copilot, add knowledge sources, test, and share. Not mobile; complex actions move to Copilot Studio.

Copilot Studio agents

Build more advanced agents with actions, topics, connectors and publish channels. Copilot Studio agents integrate automatically with Agent 365.

Requested agents

Copilot Studio agents published to Microsoft 365 Copilot or Teams can appear in Microsoft 365 admin center > Agents > All agents > Requests for publish/reject review.

Agent 365 registry

Agent 365 provides centralized visibility into agents, adoption, activity, health, metadata, ownership, platform, environment, and connectors/tools.

Agent activity view

Preview, read-only, user-scoped and 30-day retained. Shows status/timing, inputs/outputs, actions taken, and results when available.

Govern and secure

Use Agent 365 with Entra, Purview and Defender positioning for identity, access, DLP, audit, threat detection and governance actions.

Security positioning

Entra for identity/access, Purview for audit/DLP, Defender for threat detection and runtime protection.

Likely questions

Discussion answers

Is Agent 365 an agent builder?

No. Agent 365 is the control plane. Agent Builder and Copilot Studio build agents; Agent 365 observes, governs and secures them.

What if Agent 365 is not visible?

Use the feature matrix and review register as the backup. Do not promise live UI availability without tenant validation.

Why both Agent Builder and Copilot Studio?

They show two realistic paths: fast declarative agents and governed low-code production agents with actions.

Can we click block or delete?

Explain controls; do not use destructive actions in a shared demo tenant.
