Why Zava works

Zava is neutral enough for any customer audience and concrete enough for a serious business demo: retail, supply chain, finance, sales, and executive decisioning in one storyline.

Microsoft Ignite uses Zava as a fictional athletic-wear demo company. This version turns that concept into a universal Microsoft 365 Copilot demo: one urgent order, scattered context, operational risk, margin pressure, and an executive commitment.

Microsoft Learn MCP verified

Feature matrix for this demo

Status: June 3, 2026. Verified with Microsoft Learn MCP Search and Fetch. Scenario labels use visible product, feature, or agent names; Work IQ is treated as grounding context, not a live scenario title.

Copilot Chat and file upload

Can do: secure AI chat with web grounding, file upload, Copilot Pages, image generation, and agents. Limits: without a Microsoft 365 Copilot add-on license, Copilot Chat is not automatically grounded in Microsoft Graph data. Demo implication: upload or reference the Zava files explicitly.

Enterprise Data Protection

Can do: prompts and responses for Entra-signed-in users are covered by DPA and Product Terms; access controls and policies apply depending on the plan. Limits: web queries and Anthropic-based capabilities have additional data-handling notes. Demo implication: position security clearly and avoid blanket compliance claims.

Excel Edit with Copilot

Can do: edit workbooks through chat, including tables, charts, PivotTables, and formulas. Limits: formerly Agent Mode; availability depends on license, client, rollout, and tenant configuration. Demo implication: keep the prepared workbook ready; use Copilot Chat with XLSX upload as backup.

Word, Excel, and PowerPoint Agents

Can do: create Office files directly from Copilot Chat and work with organizational data for licensed users. Requirements: Anthropic models must be enabled. Limits: region, tenant, government cloud, and sovereign cloud restrictions apply. Demo implication: treat as an optional wow moment; seed files are the backup path.

Agent Builder

Can do: build declarative agents with natural language, add knowledge sources, test, and share. Limits: not available on mobile; complex actions should move to Copilot Studio; admin controls and known limitations apply. Demo implication: build the Zava Order Desk as a declarative agent and do not promise external actions.

Office app Copilot

Can do: support work in Word, Excel, PowerPoint, Outlook, and Teams; Microsoft 365 Copilot adds work grounding and app integration. Limits: app experiences vary by license, tenant configuration, and rollout. Demo implication: always keep seed files and a Chat backup path ready.

Researcher and Analyst

Can do: first-party Microsoft experiences for research and analysis tasks in Copilot Chat Tools. Limits: availability varies by tenant and cloud; not available in GCC, GCCH, or DoD. Demo implication: use as optional premium moments and keep uploaded-file Chat prompts as backup.

Teams Facilitator

Can do: collaborative real-time notes, AI-powered Q&A, timeline markers, Teams Rooms support, and meeting interaction. Limits: requires Microsoft 365 Copilot and Teams licensing; some Planner and Word or Loop capabilities are preview; not for 1:1, group, or external meetings. Demo implication: show live only when meeting policy is ready.

Teams Interpreter

Can do: real-time speech-to-speech translation in supported Teams meetings with voice simulation or automated voices. Limits: requires Microsoft 365 Copilot, Teams, and eligible base license; 20 hours per user per month included; not for town halls, webinars, Teams free, Teams Rooms scheduled meetings, or unscheduled 1:1 calls. Demo implication: optional global collaboration moment.

Prompt Coach and Visual Creator

Can do: prebuilt agents can improve prompts, writing, ideation, and visual concepts. Limits: availability depends on rollout, license, and admin controls. Demo implication: use as fast polish moments, not as proof of business-process automation.

Copilot Studio and Foundry path

Can do: move from declarative Agent Builder to richer actions, orchestration, evaluation, monitoring, and production agent engineering. Limits: needs separate governance, environment, billing, and admin configuration. Demo implication: use as the executive platform close.

Microsoft Agent 365

Can do: observe, govern, and secure agents through a centralized control plane. Agent Builder, Copilot Studio, and Foundry agents integrate with Agent 365; Copilot Studio agents appear in the registry and emit telemetry automatically. Limits: some activity views are preview and tenant/user scoped. Demo implication: show registry, activity, ownership, risk, and governance actions after the agent build.

Copilot license and Frontier

What is generally available, what is Frontier?

Status: June 3, 2026. Verified with Microsoft Learn MCP Search and Fetch. Use this tab before the demo to decide what to show live, what to position as optional, and what needs a backup path.

Microsoft 365 subscription: Copilot Chat baseline

Generally available entry point: secure AI chat grounded in the web, Copilot Pages, file upload, image generation, previous chats, agents, and Edge contextual features. This is included with eligible Microsoft 365 subscriptions, but it is not automatically grounded in all organizational data unless the user uploads or references content, uses open app context, or uses an enabled agent.

Microsoft 365 Copilot license: core value

Paid add-on: work and web chat, Microsoft Graph grounding, Microsoft 365 Copilot Search, the Microsoft 365 Copilot app, in-app Copilot experiences, built-in and custom agents, agent management, and advanced IT controls. Use this as the main licensing story for customer-facing demos.

Generally available app experiences

Worldwide availability in the Service Description lists Copilot in Teams, Outlook, Word, Excel, PowerPoint, OneNote, Loop, Clipchamp, Whiteboard, OneDrive, and SharePoint. Government cloud caveats vary by app; always check the row before promising a capability for GCC, GCCH, or DoD.

Generally available work surfaces

Microsoft 365 Copilot app, Copilot Chat, Copilot Search, Copilot Notebooks, Copilot Pages, and Copilot Prompt Gallery are documented in the Service Description. Notebooks, Search/Create AI-powered features, and work grounding require the Microsoft 365 Copilot license.

Generally available extensibility

SharePoint agents, declarative agents for Microsoft 365 Copilot, Microsoft 365 Copilot connectors, Power Platform connectors, Microsoft Purview extension points, and Viva Insights reporting are listed in the Service Description. Demo implication: Agent Builder is safe to position as the quick declarative-agent path; Copilot Studio is the production escalation path.

Researcher and Analyst agents

Microsoft-installed first-party experiences for Microsoft 365 Copilot users. Microsoft release notes mark Researcher as GA on July 22, 2025, and Learn agent-installation docs state Researcher and Analyst are deployed by Microsoft for licensed users. Caveat: built-in agents such as Researcher and Analyst are not available in GCC, GCCH, or DoD.

Frontier program

Opt-in preview channel for emerging Microsoft Copilot and Microsoft Agent 365 capabilities before GA. Requires Microsoft 365 Copilot or Microsoft Agent 365 / E7 eligibility, admin enrollment, and user access assignment. Frontier agents appear in the Agent Store with "(Frontier)" in the name and can take up to three hours to appear.

Frontier / preview examples

Microsoft Agent 365 Frontier currently documents agents with their own identity and Shadow AI. Frontier admin docs also describe Frontier agents, AI provider model approval such as Anthropic, and AI-enabled Cloud PCs. Treat Legal Agent in Word and any customer-visible "Frontier" agent as preview/tenant-gated unless it is visible in the tenant on demo day.

Presenter guidance

Say: "Generally available" when the feature is listed as worldwide available in the Microsoft 365 Copilot Service Description. Say: "Frontier / preview" when the feature requires Frontier enrollment, appears with "(Frontier)", depends on admin opt-in, Anthropic or other model approval, or is absent from the core Service Description. For every Frontier item, show the backup path first: Copilot Chat with files, Copilot in Word/Excel/PowerPoint, or seeded demo files.

Likely questions

Discussion answers

Copilot Chat vs. Microsoft 365 Copilot?

Copilot Chat is the secure entry point with web grounding, file upload, Pages, and agents. Microsoft 365 Copilot adds work grounding through Microsoft Graph and deep Office integration.

Why so many files?

Premium demos need real grounding: email, meeting notes, data, memo, risk register, Office artifacts, finance exports, and legal documents make the workflow realistic.

What is the main proof point?

The demo is not about prompting. It is a product-led decision flow: Microsoft 365 Copilot Chat, Analyst agent, Copilot in Excel, Copilot in Outlook, Copilot in Word, Copilot in PowerPoint, Agent Builder, Agent 365, Notebooks, Finance controls, and Legal Agent in Word.

What is the agent value?

The agent repeats the process for new orders and packages sources, rules, and escalation logic.
